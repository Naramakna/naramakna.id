# 🌱 Organic Growth Strategy - TikTok View Booster

## 📊 Natural Growth Patterns Implemented

### 1. **Boost Count Algorithm**
```
Low Activity (≤2 website views)    → 1-3 TikTok boosts
Medium Activity (3-5 website views) → 2-4 TikTok boosts  
High Activity (>5 website views)   → 3-6 TikTok boosts
```
- **Randomization**: ±1 boost untuk avoid pattern detection
- **Max Limit**: 6 boosts per video per cycle (reasonable growth)

### 2. **Timing Patterns (Human-Like)**
```
First Request: 3-8 seconds delay
Subsequent:    8+(i*2) to 18+(i*2) seconds delay
```
- **Progressive Slowdown**: Humans get tired over time
- **Cycle Frequency**: 15-30 minutes (peak hours) / 25-50 minutes (off-peak)

### 3. **Peak Hours Optimization**
```
Peak Times: 09:00-11:00, 15:00-17:00, 19:00-21:00
Off-Peak:   Other hours (slower activity)
```

### 4. **Smart Video Selection**
- **Max 3 videos** per cycle (avoid mass boosting)
- **High-view filter**: Only 30% chance to boost videos >10k views
- **Lookback window**: 10-20 minutes (random) instead of fixed 5 minutes

### 5. **Anti-Detection Features**
- **Random User Agents**: Mobile/Desktop/Tablet mix
- **Geographic Variation**: Different referrer sources
- **Progressive Delays**: Increase delays with each boost
- **View Count Respect**: Avoid over-boosting popular content
